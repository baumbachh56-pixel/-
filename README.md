# AIRCONA — анимация логотипа в Blender

`aircona_logo.py` — скрипт, который собирает в Blender 3D-сцену с логотипом AIRCONA и анимирует её
(5 секунд, 30 fps, 1920×1080).

## Запуск

**Внутри Blender:** вкладка *Scripting* → *Open* → `aircona_logo.py` → *Run Script*.
Пробел — просмотр, `Ctrl+F12` — рендер анимации в `aircona_logo.mp4` рядом с .blend-файлом.

**Из терминала** (сохранит `aircona_logo.blend` и отрендерит видео):

```bash
blender --background --python aircona_logo.py -- --render            # EEVEE
blender --background --python aircona_logo.py -- --render --cycles   # Cycles
```

Доп. флаги: `--samples N`, `--out путь/файл.mp4`.

## Таймлайн

| Кадры   | Что происходит |
|---------|----------------|
| 1–46    | Прорисовываются серое кольцо и тонкое внутреннее кольцо |
| 15–55   | Зелёный треугольник вращается и «выпрыгивает» с пружинкой |
| 45–72   | Тёмный шеврон падает сверху внутрь треугольника |
| 65–113  | Буквы AIRCONA появляются по одной |
| 100–150 | Мягкий наезд камеры и выравнивание, финальная пауза |

Цвета, время и размеры настраиваются в начале скрипта и в соответствующих блоках.
